# GLAMIA Training

Training code for the GLAMIA 3D gaze backbone: MobileOne-S1 with a binned pitch/yaw head, trained with a hybrid cross-entropy + expected-value L1 loss. Run `uv sync` here first (Python 3.12), and run all commands from this directory.

> The deployed GLAMIA backbone is trained **only on Gaze360**. MPIIFaceGaze training is provided for the leave-one-person-out protocol.

## Data layout

```
training/
└── data/
    ├── raw/                        # download datasets here (licenses required)
    │   ├── Gaze360/                #   contains metadata.mat + imgs/
    │   ├── MPIIFaceGaze/
    │   └── MPIIGaze/               #   only evaluation_subset/ is needed
    └── preprocessed/               # generated by the preprocessing scripts
        ├── Gaze360/
        └── MPIIFaceGaze/
```

## Preprocessing

```bash
# Gaze360 (bbox crops, no geometric normalization):
uv run preprocessing/gaze360.py --raw-dir data/raw/Gaze360 --output-dir data/preprocessed/Gaze360

# MPIIFaceGaze (geometric normalization; needs the MPIIGaze evaluation-subset sample list):
uv run preprocessing/mpiifacegaze.py \
    --raw-dir data/raw/MPIIFaceGaze \
    --sample-list-dir data/raw/MPIIGaze/evaluation_subset/sample_list_for_eye_image \
    --output-dir data/preprocessed/MPIIFaceGaze
```

All flags default to the paths shown above, so `uv run preprocessing/gaze360.py` works if you use the layout above.

## Training

```bash
# Gaze360 (train/val/test splits; ~25 epochs):
uv run train.py --config configs/gaze360_train.yaml
```

Checkpoints (`best.pth`, `latest.pth`, `epoch_N.pth`) are written to `output/gaze360_<backbone>_<timestamp>/`.

### MPIIFaceGaze leave-one-person-out protocol

```bash
bash mpii_loocv/run.sh
```

This loops over the 15 participants: builds `train.label` holding out one person, trains, evaluates on the held-out person, and reports the average angular error.

## Evaluation

```bash
uv run eval.py --config configs/gaze360_eval.yaml --weights output/<run>/best.pth
```

## Backbone

The backbone is the reparameterizable [MobileOne](https://github.com/apple/ml-mobileone)
(`src/models/backbone_mobileone.py`, local implementation; variants `mobileone_s0` …
`mobileone_s4` via the `backbone` key in `configs/*.yaml`). The released GLAMIA model
uses `mobileone_s1`; Apple-pretrained weights download automatically when
`pretrained: true`.

## MobileOne reparameterization

Fuse the multi-branch MobileOne blocks into single convs for fast inference (this is the form shipped in `../weights/`):

```bash
uv run reparameterize_mobileone.py --config configs/gaze360_train.yaml --weights output/<run>/best.pth
# → output/<run>/best_fused.pth
```
